# Third-party assets & dependencies

## 3D asset kits
| Pack | Author | License | Source |
|---|---|---|---|
| factory-kit | Kenney.nl | CC0 1.0 | https://kenney.nl/assets/factory-kit |
| city-kit-industrial | Kenney.nl | CC0 1.0 | https://kenney.nl/assets/city-kit-industrial |

CC0 = public domain; commercial use allowed, no attribution required (Kenney credited in-game anyway).
The kits live in `content/_vendor/cc0/` on disk but are NOT committed to git (freely
downloadable); the in-repo record is `content/_vendor/cc0_manifest.json` (file hashes),
`content/_vendor/cc0/cc0_inventory.json` (per-model triangle counts + dimensions) and
`content/_vendor/cc0/LICENSES.md`.

## Planned sources (per PLAN_FORGED F-01, not all downloaded yet)

## Software dependencies
All runtime/build dependencies are npm packages under their own OSS licenses
(React, Three.js, Vite, Vitest — MIT-family); see `web/package-lock.json` for the exact set.
Python mirrors use the standard library only.

Equipment references in game content use generic technology names only — no vendor
trademarks, no third-party content without a license record here.
